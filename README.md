# SnapDL — تطبيق تحميل فيديو/صوت (شبيه بسنابتيوب)

يعتمد على yt-dlp + ffmpeg (مكتبة youtubedl-android) فبيدعم يوتيوب، انستغرام، فيسبوك، تيك توك، تويتر وآلاف المواقع.

## المميزات
- لصق الرابط، أو "مشاركة" الرابط من أي تطبيق مباشرة لـ SnapDL
- عرض صورة وعنوان الفيديو
- خيارات: صوت MP3 (128 أو 320kbps) / فيديو 360 / 720 / 1080
- شريط تقدم + زر إلغاء
- الحفظ في `Download/SnapDL`
- زر تحديث المحرك (مواقع كثيرة بتغير نظامها وبتحتاج تحديث yt-dlp)

## طريقة الحصول على الـ APK (بدون ما تثبت Android Studio)
1. اعمل حساب على github.com وأنشئ Repository جديد (Private بيكفي).
2. ارفع كل محتويات هالمجلد (ملفات المشروع نفسها، مش الملف المضغوط) على الـ Repository، تأكد إن مجلد `.github` انرفع.
3. افتح تبويب **Actions** → راح تلاقي "Build APK" عم يشتغل (5-10 دقايق). إذا ما اشتغل: Run workflow.
4. لما يخلص، افتح العملية ونزّل **SnapDL-apk** من قسم Artifacts، فك الضغط وثبّت `app-debug.apk` على جوالك (فعّل "التثبيت من مصادر غير معروفة").

## بديل: Android Studio
افتح المجلد في Android Studio → Build → Build APK(s).

## ملاحظات
- استخدمه لتحميل محتوى مسموح لك تنزله (محتواك، أو المتاح للتحميل، أو للاستخدام الشخصي حسب قوانين البلد وشروط كل موقع).
- التحميل بيوقف إذا سكرت التطبيق أثناء التحميل (ما فيه Service خلفية بهالنسخة).
- محتوى خاص أو بحاجة تسجيل دخول (ستوريز حساب خاص مثلاً) ما رح ينزل.
